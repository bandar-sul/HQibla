# H9 Qibla — تطبيق قبلة ومواقيت الصلاة الاحترافي للسيارات والأجهزة الذكية

**الإصدار الرسمي:** `v10.0.0` (Build `116`)  
**التوافق:** Android 7.0+ (API 24 فأحدث) • شاشات السيارات (هافال H9، تانك GWM، BYD DiLink 5.1، ليوبارد 5، وشاشات أندرويد)، وضع تقسيم الشاشة (Split-Screen)، والهواتف الذكية.

تطبيق إسلامي متكامل ومصمم هندسياً لتجربة قيادة فاخرة وآمنة؛ يجمع بين **الدقة الفلكية لمواقيت أم القرى عبر GPS أولاً ثم التأكيد عبر الإنترنت**، و**كرة وجزيرة عائمة تفاعلية (HUD)**، و**بوصلة ثلاثية الأبعاد عديمة الارتعاش**، و**محطة طقس ورادار أمطار حي بالواقع الافتراضي**، و**نظام أذان مخصص لسماعات السيارة**.

## 🚀 أبرز متغيرات الإصدار الرسمي `v10.0.0` (Build `116`)
- **تحديث هوائي مباشر داخل التطبيق (`In-App OTA`):** تنزيل التحديث مباشرة بشريط تقدم وفحص **SHA-256** وتشغيل مُثبّت أندرويد مباشرة عبر `FileProvider` (حل جذري لمشكلة `رابط URL غير معتمد` في شاشات السيارات).
- **خروج باركود المتجر تلقائياً بدون أي تعارض:** يظهر باركود متجر هافال H9 تلقائياً بعد أي تثبيت جديد وبعد أي تحديث فور انتهاء شاشة الترحيب أو سجل التحديثات، مع إصلاح طبقة العرض لاستجابة زر الباركود وحول المطور فوراً من الإعدادات.
- **الساعة التناظرية الفاخرة الصافية:** قرص رابع بالسحب يمين/يسار بتصميم عقارب ذهبية ثلاثية الأبعاد وعقرب ثواني انسيابي خالٍ من نصوص الأيام أو الوقت المتبقي، ونقل مسافة مكة أسفل عبارة «القبلة على يسارك».
- **ثيمين فخامة عالية جدد (7 ثيمات ملكية):** **🍷 عنابي ملكي وذهب وردي** و**⚜️ بلاتينيوم وتيتانيوم ملكي** على جميع الواجهات والكرة العائمة.
- **فتح تلقائي كأساسي + فل سكرين كامل + تطبيقات سريعة مكبرة:** تشغيل مباشر مع إقلاع السيارة، وضع الشاشة الرئيسية (Launcher)، إخفاء تام لأشرطة النظام، وتوسيع نافذة التطبيقات السريعة أسفل الطقس والكرة العائمة.
- **رادار ويندي الأوروبي أولاً + تكبيرتين الأذان + أم القرى الجذرية:** فتح رادار `Windy ECMWF` أولاً باستجابة فائقة، تكبيرتين فقط بالأعلى مع رفع صوت أذان مخصص، وحساب فلكي GPS متبوعاً بتأكيد `UAQ`.

## 🌟 تفاصيل مميزات الإصدار الرسمي `v10.0.0`

### 1. 🕌 محرك مواقيت الصلاة الجذري (نظام المرحلتين: GPS فلكي أولاً + تأكيد إضافي عبر الإنترنت)
- **المرحلة الأولى — حساب فلكي فوري عبر GPS (يعمل 100% دون إنترنت):**
  - الاعتماد على معادلات **NOAA / Jean Meeus الفلكية الدقيقة (Julian Day)** لحساب ميل الشمس ومعادلة الزمن من إحداثيات الـ GPS الحية مباشرة.
  - تطبيق **قواعد التقريب الرسمية لتقويم أم القرى ومساجد المملكة (`ummulqura.org.sa`)**: الفجر `-18.5°`، الشروق `-0.8333°`، الظهر والعصر والمغرب بالتقريب الصحيح، والعشاء `+90 دقيقة` بعد المغرب (`+120 دقيقة` تلقائياً في رمضان).
  - تصحيح ربط خيار **KACST** ليتطابق مع معيار أم القرى الرسمي ومؤشر التقويم الهجري المستقر (`ICU UMALQURA`).
- **المرحلة الثانية — التحديث الإضافي والتأكيد عبر الإنترنت (`calendarMethod=UAQ`):**
  - التحقق التلقائي واليدوي عبر الشبكة لتأكيد التاريخ الهجري الرسمي ودخول شهر رمضان دون المساس بدقة حساب أم القرى.
  - منع استبدال المواقيت المؤكدة بالحسابات القديمة كل 60 ثانية، وتحديثها فقط عند تغيّر اليوم أو انتقال المركبة لمسافة تتجاوز `1 كم` أو تعديل الإعدادات.
  - عرض حالة المصدر بوضوح داخل بطاقة المواقيت (**`🛰️ GPS فلكي`** ← ثم **`🛰️ GPS + 🌐 مؤكد بالإنترنت`**).
- **تعديل مرن وعداد حي:** عداد تنازلي رقمي عالي الوضوح بالثواني للصلاة القادمة، مع أزرار `+` و `-` وقوائم مستقلة لتقديم أو تأخير كل صلاة من الصلوات الست.

### 2. 🟢 الكرة والجزيرة العائمة التفاعلية (Floating Speed & Qibla HUD)
- **أزرار اختصار واضحة بأيقونة واسم مباشر:** أزرار كبيرة وسهلة اللمس أثناء القيادة (**`🕌 المواقيت`**، **`🧭 القبلة`**، **`🌤️ الطقس`** بدرجة الحرارة الحية، **`🚀 التطبيقات`**، **`⚙️ الإعدادات`**، **`🤖 النظام`**)، مع ظهور زر **`🔇 إيقاف`** تلقائياً لإسكات الأذان بلمسة واحدة.
- **وصول سريع للتطبيقات بحجم مريح:** النقر على **`🚀 التطبيقات`** يفتح نافذة عائمة مكبرة بجميع تطبيقات السيارة (مع تثبيت المفضلة وفلتر الملاحة والصوتيات) فوق الخرائط دون مغادرتها.
- **مؤشرات HUD حية على الكرة المصغرة:**
  - توهج زمردي مضيء حول محيط الكرة عند محاذاة مقدمة السيارة لاتجاه القبلة (`±12°`).
  - سطر معلومات مصغر أسفل عداد السرعة يعرض متبقي الصلاة القادمة ودرجة الحرارة الحية.
- **ثبات وراحة بصرية أثناء القيادة:**
  - **تصفير السرعة عند الوقوف (`0 كم/س`)** ومنع القفزات العشوائية للـ GPS، مع تثبيت مؤشر القبلة عند التوقف.
  - **خفتان تلقائي ذكي (`58%` شفافية)** عند الخمول، و**التصاق مغناطيسي** بأقرب حافة أفقية للشاشة لإبقاء الخرائط مكشوفة، ومنطقة سحب سفلية (**`🗑 إخفاء`**) لإيقاف الكرة فوراً.
  - **تشغيل تلقائي مع إقلاع السيارة (`BOOT_COMPLETED` / `Quick Boot`)** مع خيارات في الإعدادات لتخصيص **حجم الكرة (`72` / `86` / `102 dp`)** و**مدة الإغلاق التلقائي للجزيرة** ومزامنة الثيمات السبعة الملكية وصيغة 12 ساعة.

### 3. 🧭 البوصلة الفاخرة والقرص الدائري بـ 4 أوجه (مع الساعة التناظرية الفاخرة الصافية) + الوصول السريع للتطبيقات
- **ترقية تصميم بوصلة القبلة لتصميم سيارات فاخر:** إطارات شامبانيا ذهبية مزدوجة الحواف، وخلفية دائرية عميقة متدرجة متكيفة مع جميع الثيمات، ونقش هندسي إسلامي دقيق، وعلامات جهات ماسية، وعقارب ثلاثية الأبعاد، ومنصة دائرية فاخرة للكعبة المشرفة تضيء باللون الزمردي عند محاذاة القبلة.
- **التبديل بالسحب يمين/يسار (4 أوجه كاملة):** كبسولة تصفح زجاجية أنيقة أسفل القرص تتيح السحب يميناً أو يساراً (أو الاختيار من الإعدادات) للتبديل وحفظ الوضع المختار تلقائياً بين:
  1. **بوصلة القبلة والكعبة المشرفة (الافتراضي):** مجسم الكعبة المشرفة ثلاثي الأبعاد مع هالة فيروزية زمردية تضيء عند مطابقة اتجاه القبلة، وعرض اتجاه القبلة نسبياً لمقدمة السيارة وتحته مباشرة المسافة بالكيلومتر إلى مكة المكرمة.
  2. **الساعة الرقمية (12 ساعة) + عداد السرعة الحي:** قوس تقدم متدرج مضيء وساعة رقمية واضحة مع كبسولة بيانات أسفلها لعرض السرعة الحية (`كم/س`) أو الصلاة القادمة ومؤشر ذهبي لموقع القبلة على الإطار.
  3. **البوصلة الرياضية (`N / E / S / W`):** بوصلة قيادة بزاوية 360° بأقواس الشمال الزرقاء والجنوب الحمراء وقلب معدني ثلاثي الأبعاد.
  4. **الساعة التناظرية الفاخرة الصافية (عقارب كلاسيكية فارهة):** عقارب ذهبية ثلاثية الأبعاد مضيئة للساعات والدقائق وعقرب ثواني انسيابي سلس، مع أرقام الساعات، ومؤشر القبلة المداري بتصميم نقي خالٍ من ازدحام التواريخ أو النصوص.
- **صفحة تطبيقات سريعة مكبرة أسفل الطقس:** زر أنيق مدمج أسفل بطاقة الطقس لفتح نافذة مكبرة وواضحة لتطبيقات الملاحة والصوتيات المثبتة بلمسة واحدة مع دعم تثبيت المفضلة.
- **تقنية Non-Jitter وتخميد السرعة (Speed Deadband):** عزل تداخل حساسات السيارات الكهربائية وتثبيت البوصلة عند التوقف في الإشارات المرورية، مع الاعتماد على توجيه الـ GPS الدقيق أثناء السير.
- **وضع الانعكاس الليلي على الزجاج الأمامي (HUD Mirroring):** قلب الواجهة أفقياً بلمسة واحدة لعكس القبلة والسرعة والاتجاه على زجاج السيارة الأمامي ليلاً.

### 4. 🌦️ محطة الطقس الحي ورادار ويندي الأوروبي (Windy ECMWF) والواقع الافتراضي
- **فتح رادار ويندي الأوروبي (`Windy ECMWF`) أولاً واستجابة فائقة:** يفتح وضع رادار ويندي الأوروبي تلقائياً كخيار أول عند الدخول للرادار بأزرار علوية فاخرة، مع تفعيل **العتاد الرسومي (`LAYER_TYPE_HARDWARE` و`OffscreenPreRaster`)**، ورفع أولوية العرض، وإضافة شريط تحميل رفيع، وإخفاء القوائم الجانبية المشتتة، والحفاظ على إحداثيات GPS الحية أثناء التكبير والتصغير، إضافة إلى رادار **Ventusky** الحي.
- **بيانات أرصاد متزامنة (`Open-Meteo`):** عرض درجة الحرارة الحالية والمحسوسة، الرطوبة، سرعة واتجاه الرياح، الأشعة فوق البنفسجية، احتمالية الأمطار، وتوقعات الساعات والأيام القادمة بتوقيت `Asia/Riyadh`.
- **محرك الطقس بالواقع الافتراضي (VR Weather Engine) بـ 6 وضعيات:** صواعق برق متفرعة، سحب ثلاثية الأبعاد، أمطار متعددة الطبقات ورذاذ ارتدادي على الشاشة، وهالة شمسية ذهبية، متكيفة مع حالة الطقس الحية أو بالاختيار اليدوي.
- **موثوقية عالية وسجل تشخيص:** محرك هجين يعمل أوفلاين في المناطق الصحراوية والبرية عبر التخزين المخبأ والتقدير الفلكي، مع تجميع الطلبات أثناء الحركة (Coalescing)، فلترة الإحداثيات الصفرية، إعادة المحاولة التلقائية، وكشف انحراف ساعة السيارة، وسجل تشخيص فوري لآخر 35 حدثاً.

### 5. 🔊 نظام تكبيرات الأذان الطبيعي ورفع أذان مخصص وصيغة 12 ساعة
- **تكبيرات الأذان (تكبيرتين فقط بالأعلى — افتراضي):** وضع خيار **«تكبيرات الأذان — تكبيرتين فقط (صوت الحرم المكي الطبيعي)»** في أعلى قائمة خيارات الصوت كخيار أول افتراضي.
- **نغمة دخول وقت الصلاة الهادئة:** نغمة طبيعية هادئة لدخول وقت الصلاة (منفردة أو تسبق التكبيرتين).
- **ميزة رفع ملف صوتي مخصص للأذان:** إمكانية اختيار ورفع أي ملف صوتي للأذان من ذاكرة الجهاز (`MP3 / M4A / WAV / OGG`) من شاشة الإعدادات، مع عرضه وحفظه محلياً لتشغيله تلقائياً في الخلفية حتى عند إغلاق التطبيق، وإمكانية استبداله أو حذفه بلمسة واحدة.
- **إخراج الصوت عبر مسار الوسائط (`STREAM_MUSIC`) مع خفض تلقائي (`70%`):** لضمان وضوح وقوة الصوت عبر سماعات السيارة الرئيسية والبلوتوث مع إعادة صوت الوسائط فور الانتهاء، وتوافق كامل مع صيغة **12 ساعة (`ص` / `م`)**.

### 6. 🪟 هندسة شاشات السيارات وفل سكرين الكامل والتعيين كأساسي
- **جعل التطبيق أساسياً يفتح مباشرة (`Auto-Launch` & `Home Launcher`):**
  - خيار **فتح التطبيق مباشرة عند تشغيل السيارة** فور إقلاع النظام.
  - خيار **تعيين التطبيق كشاشة رئيسية أساسية (Launcher)** ليعمل كواجهة تشغيل مباشرة للسيارة مع إمكانية إعادته للوضع العادي في أي وقت.
- **خيار فل سكرين لكامل الشاشة (`Edge-to-Edge Fullscreen`):** إخفاء تام لشريط الحالة العلوي وشريط التنقل السفلي وحواف القطع (Cutouts) ليمتد التطبيق على كامل مساحة شاشة السيارة والهاتف.
- **توافق تام مع وضع التقسيم (Split-Screen / GCCSplit / ECARX):**
  - دمج نوافذ الإعدادات وتحديث التطبيق والطقس وسجل التحديثات داخل حاوية التطبيق لمنع تداخلها مع شريط أو ساعة نظام السيارة الجانبية (مثل هافال H9 وتانك).
  - إزالة وإخفاء زر «⚙ الإعدادات» تلقائياً داخل واجهة خرائط الطقس والرادار وداخل شاشة الإعدادات وكافة النوافذ المنبثقة مع إزالة ارتفاعه البرمجي (`Elevation`) لمنع أي تداخل مع أزرار الضبط أو شريط وقت الرادار.
  - تحول تلقائي إلى عمود واحد فسيح في الشاشات المنقسمة، مع رفع وتوسيط زر الإعدادات على الشاشة الرئيسية وإتاحة الدخول الفوري أيضاً عبر النقر على شعار «قبلة» العلوي.
- **محرك الخطوط العربية (`FontHelper Engine`):** استخدام خطوط **Cairo** و**Tajawal** المدمجة لإظهار كافة القوائم والنصوص باللون الأبيض عالي التباين دون اختفاء الحروف على أنظمة السيارات الصينية.
- **حزمة الثيمات السبعة الملكية (بثيمين فخامة عالية جدد):** الزمردي والذهبي، الكحلي الليلي، العنبر الصحراوي، النهاري اللؤلؤي، **الوضع الليلي النقي Pure Black OLED**، و**🍷 عنابي ملكي وذهب وردي**، و**⚜️ بلاتينيوم وتيتانيوم ملكي**، بالإضافة للتبديل التلقائي وشريط الأذكار.

### 7. 🔄 التحديث الهوائي الآمن وإظهار باركود المتجر تلقائياً (OTA & Store QR)
- فحص تلقائي ويدوي للتحديثات عبر `latest.json` مع التحقق الإلزامي من بصمة الأمان **SHA-256** قبل عرض التثبيت.
- **إظهار باركود متجر هافال H9 تلقائياً بعد أي تثبيت جديد وبعد أي تحديث** لتسهيل مشاركة التطبيق ومتابعة التحديثات عبر كاميرا الجوال، مع استجابة فورية لنوافذ الباركود وحول المطور داخل الإعدادات.

## 🛠️ سجل التحديثات والتحديات الهندسية والملاحظات (`v10.0.0` / Build `116`)

### ✅ أبرز التحديات التي تم حلها جذرياً
1. **اختلاف مواقيت الصلاة وثبات التحديث عبر الإنترنت:**
   - **التحدي:** الاعتماد على API خارجي فقط يؤدي أحياناً لتأخير أو استبدال القيم ببيانات مخبأة غير محدثة أثناء القيادة.
   - **الحل:** بناء محرك مرحلتين يبدأ فوراً بالحساب الفلكي المحلي عبر إحداثيات الـ GPS (معادلات NOAA وتقريب أم القرى الرسمي +120 دقيقة في رمضان)، ثم يؤكده بالإنترنت (`calendarMethod=UAQ`) دون المساس بدقة أم القرى أو إرجاعه للقديم.
2. **عدم استجابة نوافذ «الباركود» و«حول المطور» من داخل الإعدادات:**
   - **التحدي:** امتلاك شاشة الإعدادات ارتفاعاً رسومياً (`Elevation = 24dp`) كان يجعل النوافذ المنبثقة ذات الارتفاع الافتراضي (`0dp`) تُرسم خلف الإعدادات على شاشات السيارات.
   - **الحل:** رفع طبقة عرض النوافذ المنبثقة (`36dp` Elevation وTranslationZ) لتظهر فوراً في المقدمة فوق الإعدادات دون إغلاقها.
3. **التعارض مع زر الإعدادات داخل واجهة الخرائط والرادار والتقسيم:**
   - **التحدي:** بقاء زر «الإعدادات» عائماً كان يغطي أزرار الرادار السفلية أو شريط وقت الأمطار في شاشة السيارة المقسومة.
   - **الحل:** إخفاء زر الإعدادات تلقائياً عند فتح أي واجهة خرائط أو نافذة منبثقة وإبقاء التحكم من الشريط الداخلي الموحد.
4. **مشكلة رفض التحديث وظهور «رابط URL غير معتمد» على شاشة السيارة:**
   - **التحدي:** إرسال رابط الـ APK لمتصفح السيارة الخارجي يسبب رفض الروابط المباشرة أو تعذّر التنزيل على شاشات Android 9، وتكرار `versionCode` يوقف اكتشاف التحديث.
